PHASE 1 FINAL — SOURCE-ONLY PACKAGE

This package excludes generated/heavy folders:
- node_modules
- frontend/node_modules
- frontend/dist
- .git
- Python caches and virtual environments
- private .env

After extraction:

1. Copy .env.example to .env and add your local values.

2. Install frontend dependencies:
   cd frontend
   npm ci

3. Install backend dependencies in your Python environment:
   cd backend
   python -m pip install -r requirements.txt

4. Start using your normal Docker or local development commands.

The source code, migrations, fixtures, tests, reports, package-lock files,
and Docker configuration are preserved.
